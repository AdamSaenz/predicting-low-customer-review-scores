# Predicting Low Customer Review Scores

## Project Overview
This project uses the Brazilian Olist e-commerce dataset to investigate factors associated with low customer review scores. Developed for DSC550 at Bellevue University, the analysis applies exploratory data analysis, feature engineering, and supervised machine learning to a customer experience problem.

## Project Objectives
- Explore patterns in customer reviews and order characteristics.
- Identify variables potentially associated with unfavorable review scores.
- Prepare and combine transactional datasets for predictive modeling.
- Compare classification models against a baseline.
- Evaluate the potential business applications of predicting negative customer experiences.

## Dataset
The project uses publicly available Olist Brazilian e-commerce data, including order transactions, customer reviews, payments, products, and order items.

## Methods and Technologies
- Python and Jupyter Notebook
- Pandas and NumPy
- Exploratory data analysis
- Feature engineering
- Dummy Classifier (baseline)
- Logistic Regression
- Random Forest Classifier
- Model performance evaluation

## Business Application
Identifying orders at risk of receiving low customer review scores could help e-commerce organizations investigate delivery, product, and transaction-related issues. Predictive analytics can support customer experience monitoring and operational improvement.

## Limitations
This is an academic machine learning project. Model findings are exploratory and should not be treated as a validated production prediction system without additional testing.
